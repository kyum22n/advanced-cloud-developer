# 정적 검증 — 배포 전에 «싸게» 잡는 결함

> **원칙**: 결함은 **발견이 늦을수록 비싸집니다.** 정적 검증은 실행조차 하지 않고 잡아내는 가장 싼 단계입니다.

---

## 1. 두 계층으로 나눈 이유

| 계층 | 실행 파일 | 필요한 것 | 무엇을 잡나 |
| --- | --- | --- | --- |
| **1차** | [`verify_static.py`](verify_static.py) | **Python + Node 만** | 계약 위반 · 비밀 하드코딩 · 컨테이너 보안 · 구문 오류 |
| **2차** | [`run_static_all.ps1`](run_static_all.ps1) | 언어별 도구 | 타입·버그 패턴·코딩 규칙·단위 테스트 |

> 🔑 **1차는 «도구가 없어도 잡아야 하는 것»만 봅니다.** 폐쇄망·신규 PC·CI 초기 상태에서도 최소 방어선이 항상 작동하도록 표준 라이브러리만 씁니다.

---

## 2. 1차 검사 항목

| 분류 | 검사 | 실패 시 의미 |
| --- | --- | --- |
| **[구조]** | 프로젝트별 필수 파일 존재 | 빌드·배포가 중간에 멈춘다 |
| **[계약]** | 세 백엔드가 엔드포인트 6종을 모두 구현 | **프런트엔드를 바꾸면 깨진다** |
| **[설정]** | 필수 환경 변수 6종 사용 | 환경 간 이식성이 없다(NFR-07 위반) |
| **[E2E]** | 두 프런트엔드가 **동일한 `data-testid`** 사용 | 프런트엔드 교체 시 E2E 를 다시 써야 한다 |
| **[컨테이너]** | 비루트 실행 · 멀티스테이지 · 가변 태그 금지 | 운영 보안 기준 미달(P-06·P-07) |
| **[보안]** | 비밀 하드코딩 · `0.0.0.0/0` | **유출·전면 개방** |
| **[구문]** | Python · JavaScript · JSON | 배포 후에야 실패를 안다 |

```powershell
cd 개발\정적검증
python .erify_static.py          # 리포트: reports\static_1st.json
```

---

## 3. 2차 검사 항목 (언어별)

| 프로젝트 | 도구 | 무엇을 보나 |
| --- | --- | --- |
| Spring Boot | **Checkstyle** · **SpotBugs** · JUnit | 코딩 규칙 · 버그 패턴 · 단위 테스트 |
| NestJS | **`tsc --noEmit`(strict)** · **ESLint** · node:test | 타입 안정성 · `any` 금지 · 단위 테스트 |
| FastAPI | **Ruff**(E/F/W/I/N/UP/B/**S**/C4/SIM/RET) · **mypy strict** · pytest | 린트 · 보안(S) · 타입 · 단위 테스트 |
| HTML5 | **ESLint** | 구문·미사용 변수·`==` 금지 |
| Vue | **ESLint + eslint-plugin-vue** · `vite build` | 템플릿 규칙 · **`v-html` 금지** · 빌드 성공 |

```powershell
cd 개발\정적검증
pwsh -File .un_static_all.ps1                # 최초 실행(의존성 설치 포함)
pwsh -File .un_static_all.ps1 -SkipInstall   # 설치 생략
```

> ⚠️ **Java 검증에는 `JAVA_HOME` 이 필요합니다.** 미설정이면 해당 단계를 **건너뛰었다고 명시**하고 다음으로 넘어갑니다 — «통과»로 집계하지 않습니다.

## 4. 배포 파이프라인과의 연결

```
개발/정적검증  →  배포/<env>/30_build  →  50 단위  →  60 통합  →  70 E2E  →  80 검증
   (실행 없음)        (이미지 생성)        (순수 로직)   (API+DB)   (브라우저)   (운영 기준)
   가장 쌈 ──────────────────────────────────────────────────────────────► 가장 비쌈
```

| 여기서 잡으면 | 여기서 못 잡으면 |
| --- | --- |
| 수 초 안에 수정 | 빌드 3분 → 배포 5분 → 테스트 3분 뒤에 발견 |
| 클라우드 비용 0 | stg·prd 리소스를 쓰고 나서 되돌림 |
