## ⚠️ 0. 먼저 확인해야 할 전제

이 설계는 **모델 제원을 파라미터로 받도록** 만들어졌습니다. 특정 수치를 문서에 박아 두지 않은 이유는, 모델 카드의 값이 바뀌면 문서 전체가 조용히 틀려지기 때문입니다.

| 확인 항목 | 어디서 | 왜 필요한가 | 어디에 기록하나 |
| --- | --- | --- | --- |
| **총 파라미터 수** | 공식 모델 카드 | **VRAM 소요량**을 결정 | `config/model.json` |
| **활성 파라미터 수**(MoE 인 경우) | 모델 카드 | **연산량·처리량**을 결정 | 〃 |
| 레이어 수 · KV 헤드 수 · 헤드 차원 | `config.json` | **KV 캐시 크기**를 결정 | 〃 |
| 최대 컨텍스트 길이 | 모델 카드 | KV 캐시 상한 | 〃 |
| **라이선스** | 저장소 `LICENSE` | **상업적 사용·재배포 가능 여부** | 〃 |
| 지원 정밀도(FP16/FP8/INT4) | 모델 카드 · 커뮤니티 양자화본 | 비용에 **가장 큰 영향** | 〃 |
| 서빙 엔진 지원 여부 | vLLM/SGLang 릴리스 노트 | 아키텍처가 지원되지 않으면 **시작조차 못 함** | 〃 |

> 🚫 **이 문서는 GLM 5.2 의 구체적 제원을 단정하지 않습니다.** 값을 확인해 `config/model.json` 에 채우면, 여기의 모든 계산식·스크립트가 그 값을 사용합니다.
> 🔎 **가장 먼저 확인할 것은 «vLLM 이 이 아키텍처를 지원하는가»입니다.** 지원되지 않으면 나머지 설계가 무의미해집니다.

```powershell
# 제원을 채운 뒤, 필요한 GPU 수와 예상 비용을 계산한다
cd 모델\GLM5.2\config\scripts
python .\sizing.py          # VRAM·GPU 수 산출
python .\price_check.py     # Azure 실시간 단가 조회
```
