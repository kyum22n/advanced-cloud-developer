## 2. 인수조건(AC) 대비 결과

| AC-ID | 내용 | 커버 TC 수 | Pass | 상태 |
|---|---|---|---|---|
| AC1 | 정상: 분석 실행 → 프로젝트 구조·기술스택·커밋 요약 리포트 표시 | 7 | 7 | **O** |
| AC2 | 정상: Notion 업로드 → 성공 시 페이지 링크 표시 | 2 | 2 | **O** |
| AC3 | 정상: 이력 목록에서 과거 분석 재조회 | 3 | 3 | **O** |
| AC4 | 예외: 비공개/미존재/형식오류 레포 안내 | 4 | 4 | **O** |
| AC5 | 예외: GitHub Rate Limit 초과 안내 | 1 | 1 | **O** |
| AC6 | 예외: Notion 토큰 미설정/만료 안내(토큰값 비노출) | 2 | 2 | **O** |

**AC2 검증 완료**: 사용자가 Notion Integration Token·상위 페이지 ID를 직접 발급해 `.env`에 저장 → 서버가 "설정됨" 여부만 확인(값은 미확인) 후 재기동 → `POST /api/analyses/{id}/notion-upload` 실제 호출 결과 `app.notion.com` 도메인의 실제 페이지가 생성되고 링크가 반환됨을 API(TC-I7)와 UI(TC-E7, `07_Notion업로드성공.png`) 양쪽에서 확인했습니다.

**AC5(Rate Limit) 관련**: `GITHUB_TOKEN` 적용 후에는 API 한도가 5,000회/시간으로 늘어나 한도 초과를 다시 실제로 재현하기 어려워, TC-E4(E2E)는 재현이 쉬운 **AC4(존재하지 않는 레포, 404)**로 캡처를 교체했습니다. AC5는 토큰 적용 이전 세션에서 실제로 한도를 소진시켜 확보한 **TC-I3(통합, 429 응답 확인)** 기록으로 계속 커버됩니다.

## 3. 실제로 확인된 것 (재현 가능한 사실)

### 1차 테스트 (비인증, Rate Limit 60회/시간)
- 인증 없이 GitHub 공개 API로 **18개 실제 공개 레포**(react, vue, vscode, linux, cpython, go, rust 등)를 분석해 저장
- 분석 과정에서 GitHub Rate Limit(비인증 60회/시간)을 실제로 소진시켜 **AC5 예외를 인위적 mock 없이 실제로 재현**(TC-I3 근거)

### 2차 테스트 (GITHUB_TOKEN 적용 후)
- `.env`의 `GITHUB_TOKEN` 설정을 사용자가 직접 완료 → `GET /rate_limit` 조회 결과 **5,000/5,000** 확인(비밀값인 토큰 실값은 확인하지 않고 "설정됨" 여부만 확인)
- `expressjs/express` 레포를 인증 상태로 재분석 → **"프로젝트 구조" 절**(최상위 디렉터리별 파일 수: test/ 112개, examples/ 80개, lib/ 6개, .github/ 5개, 총 213개 파일)이 실제 GitHub Git Trees API 응답 기반으로 정상 생성됨을 확인
- 리포트 제목·안내 문구가 "포트폴리오/이력서 첨부용"으로 반영된 것을 실제 화면에서 확인
- 존재하지 않는 레포(`this-org-does-not-exist-xyz/private-tool`)로 AC4(404) 예외를 인증 상태에서도 동일하게 재현
- Notion 토큰 미설정 상태에서 업로드 시 **401 응답에 토큰 실값이 전혀 포함되지 않음**을 응답 바디로 직접 확인(AC6)

### 3차 테스트 (NOTION_TOKEN·NOTION_PARENT_PAGE_ID 적용 후 — 최종)
- `.env`의 `NOTION_TOKEN`·`NOTION_PARENT_PAGE_ID` 설정을 사용자가 직접 완료 → 서버가 "설정됨" 여부만 확인 후 재기동
- `octocat/Hello-World`(API 직접 호출, analysisId=29)와 `octocat/Spoon-Knife`(UI 클릭 플로우, analysisId=30) 두 건을 각각 실제로 Notion에 업로드 → 응답 200, `report.notion_url`이 `app.notion.com` 호스트로 저장됨을 확인(URL 전체 값은 페이지 링크일 뿐 비밀값이 아니므로 캡처에 노출해도 무방 — 토큰 실값과는 별개)
- 최종 분석 이력 **30건**(성공 25·실패 5) 누적, 엑셀 내보내기 재확인
