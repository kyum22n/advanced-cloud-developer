Demo Walkthrough

레포 인사이트 · GitHub → Notion 포트폴리오 리포트 도구

dev 환경(k3d, http://localhost:8080)에서 실제로 실행한 화면을 순서대로 재생합니다.

STEP 1

초기 화면 — 레포 URL 입력

메인 화면 접속 후 분석할 GitHub 공개 레포 URL을 입력합니다. 진입 장벽 없이 URL 하나만 필요합니다.

STEP 2

분석 실행 → 결과 확인

프로젝트 구조·아키텍처 패턴 추정·기술 스택 구성비·최근 커밋 요약이 실제 GitHub 데이터로 채워집니다. 수작업 20~30분이 수십 초로 단축됩니다.

STEP 3

Notion 업로드 완료

"Notion에 업로드" 버튼 클릭 한 번으로 app.notion.com에 실제 페이지가 생성되고, 업로드 완료 링크가 화면에 표시됩니다.

STEP 4

분석 이력 목록

과거에 분석한 레포 이력을 언제든 다시 조회할 수 있습니다. 성공/실패 상태와 실패 사유도 함께 기록됩니다.

facebook/react 레포 분석 실사용 예시 · 자동 재생 (4초 간격, 마우스를 올리면 일시정지)
